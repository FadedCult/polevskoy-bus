# Полевской Bus

Приложение для расписания городского транспорта Полевского.

## Что внутри

- Главная с поиском остановок и новостями
- Раздел маршрутов с таблицами расписаний
- Карта остановок на OpenStreetMap
- Профиль/служебный экран

## Технологии

- React 19
- Vite 8
- Tailwind CSS v4
- Capacitor
- Leaflet

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура

- `src/App.tsx` - переключение экранов
- `src/pages/` - страницы приложения
- `src/components/` - общие компоненты
- `src/data/` - расписания и справочники

## Примечание

Данные расписания берутся из `src/data/transitData.json`.
